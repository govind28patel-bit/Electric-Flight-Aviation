# Vayu · Electric Flight Aviation

UX case study by Govind Patel (Demola, 2026): how a 40-minute charging stop on regional electric flights in India can become a reason to fly.

**Live case study:** https://govind28patel-bit.github.io/Electric-Flight-Aviation/

Includes secondary research (27 sources), as-is and to-be service blueprints, 13 ideas, five films, the Vayu card, and the full app and website screens.
